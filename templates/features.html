Understanding Features

The SimCLR encoder produces 512-dimensional feature vectors that represent the visual content of images in a learned latent space. These features:

  • Are learned through contrastive learning without labels
  • Encode semantic similarities between images
  • Can be used for downstream classification with minimal labels (linear evaluation)
  • Provide insights into learned visual representations
