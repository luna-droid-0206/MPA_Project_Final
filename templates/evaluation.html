How to Generate Evaluation Results
  1. Train the supervised model: python train_supervised.py
  2. Pretrain with SimCLR: python train_simclr.py
  3. Run linear evaluation: python train_linear.py
  4. Evaluate all models: python evaluate.py
  5. Results will be saved to: checkpoints/evaluation_results.json
What to Expect

Once evaluation is complete, you'll see:

  • Supervised Baseline Accuracy: ~95-97% (trained on full labels)
  • Linear Eval Accuracy: ~90-93% (features from self-supervised learning)
  • Per-class breakdown showing which categories are easier/harder to classify
  • Performance comparison visualizations
