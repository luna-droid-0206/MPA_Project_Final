Overview

SimCLR (Simple Contrastive Learning of Visual Representations) is a self-supervised learning method that learns meaningful visual representations without requiring labeled data. This web application demonstrates how SimCLR can match or exceed supervised learning performance on CIFAR-10.

Key Features
  • Self-Supervised Learning: Learns representations without labels
  • Contrastive Loss: Uses NT-Xent (Normalized Temperature-scaled Cross Entropy) loss
  • Data Augmentation: Leverages strong augmentations to create different views
  • Transfer Learning: Learned features transfer well to downstream tasks

Architecture

SimCLR Framework

SimCLR consists of four main components:

1. Data Augmentation

Creates two random augmented views of each image

RandomCrop, ColorJitter, RandomGrayscale, GaussianBlur
2. Encoder Network

ResNet-18 base model extracts features

Output: 512-dimensional feature vectors
3. Projection Head

Non-linear MLP projects features to lower dimension

512 → 512 → 128 dimensions
4. Contrastive Loss

NT-Xent loss maximizes similarity of augmented pairs

Batch size: 256, Temperature: 0.5

Usage Guide

Training Models
# Supervised baseline training
python train_supervised.py

# Self-supervised pretraining with SimCLR
python train_simclr.py

# Linear evaluation on frozen encoder
python train_linear.py

# Evaluate all models
python evaluate.py

# Run full pipeline
python main.py --all
Web Interface
# Start the web app
python app.py

# Open browser to
http://localhost:5000

Available Models

Supervised Baseline

Standard supervised ResNet-18 trained on fully labeled CIFAR-10 data. Represents the upper performance bound using labels.

Type: Full neural network
Training: 50 epochs, Cross-entropy loss
Expected Accuracy: ~95-97%

Linear Evaluation

Linear classifier trained on frozen SimCLR encoder features. Tests quality of self-supervised representations.

Type: Frozen encoder + linear layer
Training: 50 epochs, Cross-entropy loss
Expected Accuracy: ~90-93%

Web App Features

Image Classification

Upload images and get predictions from both supervised and self-supervised models. Compare how different learning approaches classify the same image.

Feature Extraction

Extract 512-dimensional feature vectors from the SimCLR encoder and visualize their statistical properties and distributions.

Model Evaluation

View comprehensive evaluation metrics comparing supervised and self-supervised approaches, including per-class performance breakdowns.

Automatic Hardware Acceleration

Automatically detects and uses GPU if available, falls back to CPU for compatibility.
